# Screenshot assets

Drop the app screenshots referenced by the README here, using these exact
file names:

| File | Suggested capture |
| --- | --- |
| `home.png` | Library home (tracks tab, glass nav) |
| `now_playing.png` | Now-playing screen with cover art |
| `synced_lyrics.png` | Synced lyrics overlay mid-song |
| `queue_sheet.png` | Queue sheet with drag handles |
| `discovery.png` | Discovery / online sources screen |
| `desktop.png` | Desktop (Windows/Linux) window |

Recommended: PNG, ~1080 px wide (phone) / ~1600 px (desktop), dark theme for
consistency. The README renders them in a 2-column grid automatically.
